# Sandboxed Second Pass

**What you get:** every pull request gets an independent, sandboxed code review from Grok Build (open-source coding harness). Findings ranked blocker / major / nit. Ends with a clear VERDICT.

**Why it matters:** second opinions catch money, security, and deploy mistakes before they ship — without giving the reviewer write access to your repo.

**How it works:**
1. PR opens or updates
2. Diff is sent to a read-only sandboxed agent
3. Sticky comment updates with VERDICT: APPROVE | REQUEST_CHANGES | HOLD
